# Majd Driving School

A Flutter mobile application designed to help users practice driving license traffic sign questions.

## Features
- 25 traffic sign questions
- 10 randomly selected questions per quiz
- Four answer choices for each question
- Immediate feedback for correct and incorrect answers
- Quiz progress indicator
- Final score and results
- Option to restart the quiz

## Technologies
- Flutter
- Dart
- Android

## How It Works
1. Open the application.
2. Press **Start Practicing**.
3. Answer 10 randomly selected traffic sign questions.
4. View your final score.
5. Restart the quiz or return to the home screen.

## Project Information
This application was developed for the CSCI410 Mobile Application course.

The application does not use a local or online database. Traffic sign questions are stored in the Dart source code.
